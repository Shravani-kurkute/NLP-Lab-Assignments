\# NLP Lab Assignments

**Natural Language Processing Laboratory — Practical Assignments**

A collection of Natural Language Processing (NLP) laboratory assignments developed as part of academic coursework. This repository contains implementations, experiments, datasets, evaluation results, visualizations, notebooks, and assignment reports.

## 📚 Assignments

The repository is organized assignment-wise for easy navigation.

| Assignment | Description | Key Deliverables |
|---|---|---|
| Assignment 1 | Bigram Language Model | Python implementation, corpus files, test sentences, and results |
| Assignment 2 | Multilingual Text Analysis | English, Hindi, and Marathi text processing, analysis, and visualizations |
| Assignment 3 | Part-of-Speech (POS) Tagging | Hidden Markov Model (HMM), Viterbi decoding, evaluation, and error analysis |
| Assignment 4 | Country Prediction Using Word Embeddings | Word-vector analogies, country prediction, evaluation, and visualizations |
| Assignment 5 | Sentiment Analysis and Research Paper Replication | Amazon review sentiment classification and experiments inspired by Pang, Lee, and Vaithyanathan (2002) |
| Assignment 6 | News Article Classification | TF-IDF feature extraction, Multinomial Naive Bayes, model evaluation, and classification reports |

*Each assignment folder contains the files and outputs relevant to its implementation. Refer to the individual assignment README files, where available, for specific instructions.*

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/Shravani-kurkute/NLP-Lab-Assignments.git
cd NLP-Lab-Assignments
```

### 2. Navigate to an assignment

For example, to access Assignment 6:

```bash
cd "Assignment 6"
```

### 3. Set up the Python environment

If the assignment includes a `requirements.txt` file, create and activate a virtual environment:

```bash
python3 -m venv .venv
source .venv/bin/activate
```

Install the required dependencies:

```bash
python -m pip install --upgrade pip
pip install -r requirements.txt
```

On Windows, activate the environment using:

```powershell
.venv\Scripts\activate
```

### 4. Run the implementation

Follow the instructions in the assignment's README. For example, if Assignment 6 contains the following scripts:

```bash
python train_model.py
python test_model.py
```

Run these commands from the Assignment 6 directory. Script names and execution steps may differ for other assignments.

## 📝 Reproducibility

To reproduce an experiment:

1. Open the relevant assignment directory.
2. Read its README and check its `requirements.txt`.
3. Place any required datasets in the documented locations.
4. Install the dependencies.
5. Run the specified Python script or Jupyter notebook.
6. Review the generated results and visualizations.

Some experiments may require downloading datasets separately. Check the assignment-specific instructions before execution.
